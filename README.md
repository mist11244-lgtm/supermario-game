# SNOWBELL CUP — 마리오 윈터 카트

HTML, CSS, JavaScript와 Canvas 2D로 만든 크리스마스 아이스 카트 레이싱 팬 게임입니다.

## 실행

`dist/index.html`을 브라우저에서 열면 바로 실행됩니다. 설치나 빌드가 필요하지 않습니다. 개발용 서버는 저장소 루트에서 `python -m http.server 8080`으로 시작하고 `http://localhost:8080/dist/`에 접속하세요.

- 마리오, 루이지, 피치, 요시, 키노피오, 쿠파 중 선택
- 서로 다른 속도와 핸들링을 가진 6명 / 3바퀴 경쟁
- 얼음 조향 관성, 드리프트 미니 터보, 가속 패드, 코인
- 선물 상자 아이템: 버섯, 무적 스타, 눈꽃 폭탄, 등껍질
- Web Audio로 실시간 생성되는 통통 튀는 겨울 멜로디와 효과음
- 일시정지, 재시작, 음소거, 전체화면, 모바일 터치 조작

## 조작

| 키 | 기능 |
| --- | --- |
| ← → 또는 A D | 차선 이동 |
| ↑ W / ↓ S | 가속 / 브레이크 |
| Shift + 조향 | 드리프트 충전, Shift 해제로 부스트 |
| Space | 아이템 사용 |
| P / Esc | 일시정지 / 재개 |

자동 가속은 기본으로 켜져 있습니다. 소리는 브라우저 정책에 따라 시작 버튼을 누른 뒤 재생됩니다. 모바일에는 터치 조작 버튼이 표시됩니다. 외부 이미지나 오디오 파일 없이 동작하며, Google Fonts 연결이 없으면 시스템 글꼴을 사용합니다.

## GitHub Pages

`.github/workflows/pages.yml`은 main 브랜치에 푸시하면 `dist`를 배포합니다. 저장소 Settings → Pages → Source에서 GitHub Actions를 선택하세요.

## 검증

`node tests/smoke.cjs` — 캐릭터 선택, 시작 카운트다운, 가속, 드리프트, 아이템 수집/사용, 일시정지, 3바퀴 완주 및 재시작을 검사합니다.

## 안내

Nintendo와 무관한 비공식 팬 프로젝트입니다. 캐릭터 이름은 각 권리자에게 귀속됩니다. 그래픽은 SVG와 Canvas로 직접 그렸고, 오디오는 브라우저에서 합성합니다. 상용 음원과 게임 원본 리소스는 포함하지 않습니다.
